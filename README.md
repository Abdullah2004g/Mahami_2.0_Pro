# Mahami 2.0 Pro — مهامي

تطبيق إنتاجية عربي RTL مبني بـ Expo / React Native، يعمل محليًا بدون إنترنت لحفظ المهام والإعدادات.

## الواجهات
- الرئيسية الديناميكية حسب وقت الجهاز.
- قائمة المهام مع الأولويات والإنجاز والحذف.
- مؤقت تركيز 15/25/45/60 دقيقة مع إشعار عند الانتهاء.
- إحصائيات أسبوعية ونسبة الإنجاز والأولويات.
- إعدادات المظهر: فاتح / تلقائي / داكن.

## التشغيل وبناء APK
1. ثبّت الاعتمادات: `npm install` أو `yarn install`.
2. حدّث `extra.eas.projectId` في `app.json` إلى Project ID الخاص بمشروع Expo.
3. استخدم EAS لبناء APK عبر GitHub Actions كما في `.github/workflows/build-apk.yml`.

لا يحتاج المشروع إلى Android Studio أو Android SDK على جهازك إذا تم البناء عبر EAS.
